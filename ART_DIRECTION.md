# Art Direction

## Character

The visual language is warm, graphic and slightly playful. Characters are original arrangements of simple shapes with readable heads, clothing colours and small walking poses. They are not copied from any reference game.

## Palette

| Role | Colour |
|---|---|
| Village green | `#173F35` |
| Friendly green | `#286657` |
| Paper | `#FFFDF7` |
| Warm cream | `#FBF7EA` |
| Highlight gold | `#E9B949` |
| Accent red | `#B6484C` |
| Text | `#20342F` |

World colours use muted brick, timber, planting and river blues. Important prompts use cream/gold so they remain legible over the map.

## Typography and spacing

Fraunces is used for friendly display headings, with DM Sans for interface text and system fallbacks. Interface spacing follows a practical 4/8px rhythm. Touch targets are at least approximately 44×44 CSS pixels.

## Icons and assets

Milestone one uses CSS, emoji for noncritical category decoration and Phaser-drawn shapes. No proprietary map tiles, photographs, external sprite sheets or archive assets are used. Future exported artwork should keep editable sources separate from optimised web files and record its licence in `ATTRIBUTION.md`.
